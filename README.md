# Forensic

Sau đây mình sẽ giới thiệu cho các bạn về Forensic!!!
  - Forensics là thể loại nơi chúng phải phân tích chứng cứ kỹ thuật số (file, ảnh, ổ đĩa, mạng, log, v.v.) để tìm manh mối hoặc flag.
  - Các dạng về forensic:
    + Disk / Memory image  -->    Phân tích ổ đĩa ảo (.dd, .img) hoặc dump RAM để tìm dữ liệu ẩn
    + Network capture (PCAP)  -->  Phân tích file .pcap để tìm dữ liệu truyền qua mạng
    + Steganography  -->   Ẩn thông tin trong hình, âm thanh, video
    + File corruption / recovery  -->  File bị hư, sai định dạng, thiếu header
    + Log analysis  -->  Phân tích log hệ thống, web server, trình duyệt, app
    + Email / PDF / Document  -->  Tìm metadata, macro, link ẩn trong tài liệu
    +  Malware forensics  -->  Phân tích hành vi, chuỗi, file dropper
